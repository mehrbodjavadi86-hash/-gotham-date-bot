# Gotham Date Telegram Bot

This project is a Telegram bot for the Gotham Date website.

## Environment Variables

BOT_TOKEN=توکن ربات را اینجا قرار نده
ADMIN_CHAT_ID=Chat ID ادمین

## Netlify

The bot runs using Netlify Functions.

Function:
netlify/functions/telegram.js

Setup:
netlify/functions/setup.js

Do not store secret tokens directly in the source code.
