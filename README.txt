GOTHAM DATE TELEGRAM BOT

1) در BotFather یک بات بساز و BOT_TOKEN را بگیر.
2) بات را اجرا کن و /start را بزن.
3) برای اینکه اعلان‌ها برای خودت بیاید، chat ID خودت را در ADMIN_CHAT_ID قرار بده.
4) نصب:
   pip install -r requirements.txt
5) اجرا در ویندوز:
   set BOT_TOKEN=توکن_بات
   set ADMIN_CHAT_ID=چت_آیدی_خودت
   python bot.py

برای تست سریع می‌توانی مقادیر را موقتاً مستقیم داخل bot.py قرار دهی، ولی توکن بات را عمومی منتشر نکن.

جریان بات:
آره/نه -> انتخاب ماه -> انتخاب روز -> انتخاب مکان -> تأیید -> ارسال اعلان به صاحب بات
